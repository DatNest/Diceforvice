# 🎲 Dice for Vice — DicePlot Simple

Адаптация расширения [DicePlot](https://github.com/kkkangkkang-creator/ST-DicePlot) для SillyTavern. Оригинальное расширение разработано **kkkangkkang-creator**. Простая версия сделана для DatNest.

## Установка

В SillyTavern выбери **Расширения → Установить расширение**, вставь:

```text
https://github.com/DatNest/Diceforvice
```

Если оригинальный DicePlot уже установлен, **удали или отключи его перед установкой**, чтобы две версии не конфликтовали. Никаких изменений в пресете, скриптов или ручного заполнения характеристик не требуется.

## Простой режим (по умолчанию)

- Перед ответом расширение бросает **2d20** без дополнительного запроса к ИИ.
- Модель применяет результаты **только к значимым действиям с неопределённым исходом**. Для обычного разговора и повседневных дел проверка не нужна.
- Сложность препятствия: **7 / 11 / 15 / 19**. Преимущество или помеха зависят от **уже установленных** навыков, ресурсов и обстоятельств персонажа. Отдельно вводить параметры не нужно.
- Один бросок может разрешить проверку **в этом же ответе**. На экране может появиться небольшая плашка с результатом; служебный тег скрывается.
- Броски хранятся в сообщениях **своего чата** и не смешиваются между чатами. Свайп по умолчанию использует тот же результат, но повторный бросок можно включить в настройках.
- Расширение не определяет чувства, согласие или романтические решения персонажей с помощью кубиков.

В настройках есть переключатель **Пошаговый**, который возвращает оригинальную двухэтапную систему `<check/>` и `<judged/>` для желающих.

**Ограничение:** корректное применение проверки зависит от соблюдения инструкции языковой моделью. Механика не заменяет движок с гарантированной симуляцией действий.
